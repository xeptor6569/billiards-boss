## Billiards Boss Documentation

This folder contains all project documentation for local development, CI/CD, deployment, and operations.

- **Quickstart**: See `quickstart.md` for a 5–10 minute guide to get Billiards Boss running locally.
- **Setup**: See `setup.md` for installing dependencies, configuring the app, and running it in Docker.
- **Environment configuration**: See `env-setup.md` for how `.env` files work across local, dev, and production.
- **CI/CD**: See `ci-cd-setup.md` for GitHub Actions and self-hosted runner setup.
- **Deployment**: See `deploy.md` for deploying to dev/production on your Proxmox VM and Cloudflare.
- **Debugging workflows**: See `debug-workflow.md` for debugging failed GitHub Actions runs.
- **Docker & runner cleanup**: See `docker-cleanup.md` for disk space management on your runner.
- **Multi-environment setup**: See `multi-env-setup.md` for running dev and prod on the same machine.
